# Project workflow

The user wants completed changes to this project always pushed to GitHub.

- After the checks appropriate to a change pass, commit the completed changes and push them to the `github` remote at `https://github.com/elshod-gosling/ZEHN-EDU.git`. The project's current branch is `main`.
- A Sites source push or deployment does not replace the GitHub push. Complete both when the task also updates the hosted website.
- Preserve unrelated local changes. Never force-push or discard remote commits; integrate remote changes safely if needed.
- Report a failed or blocked push clearly. A later explicit request for local-only work or no push overrides this default.
