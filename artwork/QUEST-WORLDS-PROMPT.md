# Quest worlds artwork

Generated using the built-in ImageGen tool. The original PNG is retained as `quest-worlds.png`; `dist/assets/quest-worlds.webp` is a compressed format conversion for the website. CSS selects individual atlas quadrants. No creative postprocessing was applied.

## Final prompt

Use case: stylized-concept. Asset type: a single 2-by-2 square artwork atlas for four world cards in a children's learning game launcher. Create a polished, art-directed 3D miniature game world atlas, square 2048x2048. Four EQUALLY SIZED square panels touching seamlessly at exactly the horizontal and vertical midpoint, absolutely no gutters, no borders, no text, no letters, no numbers, no UI. Each scene must be independent and completely contained inside its own quadrant with comfortable margins. Style: beautifully crafted isometric low-poly toy dioramas, sharp geometry, matte materials, playful game environments with detailed vegetation, soft sunlight and ambient shadows, coherent camera across panels, bold beautiful colors, charming without babyish eyes on everything. TOP LEFT: cobalt-blue and mint robotic coding lab on a small lush floating island, tiny friendly box-shaped white robot with blue visor, chunky monitors, circuit paths, mint cuboid trees; sky background pale blue. TOP RIGHT: sunny peach and pink creative studio on a floating island, sculptural folded sheets, colorful geometric stationery, chunky three-dimensional chart bars and paper airplane, a tiny orange blocky explorer; soft peach background. BOTTOM LEFT: lavender and emerald math adventure island with stone temple, geometric arches, floating faceted crystals, winding steps, an orange explorer, blocky verdant plants; lavender sky background. BOTTOM RIGHT: warm golden racetrack island with a tiny blue racing car, sculptural white keyboard keys along a curved orange track, checkered finish flag and blocky palms; soft yellow background. Each image fills its quadrant with a strong recognizable central scene; avoid infographic icons, cheap vector art, glossy plastic, watermarks, branded characters or logos. This is finished illustration, not a website mockup.
